# 飞书（feishu）

让 Agent 经**本机已登录的飞书 CLI（lark-cli）**，或**你填的飞书登录 token**，读写飞书文档、表格、多维表格、评论、知识库和妙记。全局插件，对所有对话生效；手动安装（设置 → 插件）。

## 用之前

```bash
npx @larksuite/cli@latest install
lark-cli auth login
```

留空「lark-cli 路径」时自动找（PATH、Windows 注册表里新加的 PATH、npm 全局目录、常见安装目录），找到的位置显示在设置的「运行状态」里；装在别处就填完整路径。

### 不装 lark-cli：用 token 登录（1.1.0 起，要面板插件接口 18）

在插件参数「登录」里填 `user_access_token`（u- 开头，约 2 小时过期）；想自动续期再填 `refresh_token` 和拿 token 用的应用的 App ID、App Secret。
令牌、App Secret 是面板的保密项：加密存在本机数据目录 `secrets/`，不进设置文件、不进环境变量、不随数据备份导出，网页上只显示末 4 位。

「登录方式」：自动（找得到 lark-cli 就用它，找不到用 token）/ 只用 lark-cli / 只用 token。token 方式直接调飞书开放接口（`server/feishu/openapi/`，按「工具.动作」登记），权限闸、审计和 lark-cli 那条路是同一套：

| 能做                                                                                                                    | 只能经 lark-cli                                                            |
| ----------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 读文档（整篇纯文本）、知识库、表格、多维表格、评论、妙记、Markdown 文件；搜文档；写表格、多维表格；加 / 回复 / 解决评论 | 改文档正文、新建文档、改 Markdown 文件、搜妙记、按段落读文档、评论到某一块 |

## 权限（按对话）

| 操作       | 什么时候直接做                                                                                                                              | 其余情况                                                    |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| 读         | 用户在这个对话里亲口贴过的链接（wiki 链接解开后同一篇也算）、卡片上选了「本对话不再询问」的、这个对话新建的、父对话能读的、信任的知识库空间 | 弹卡，卡上写来源（哪篇文档里引用的 / 不在你给的链接范围内） |
| 写         | 卡片上选了「本对话不再询问」的、这个对话新建的                                                                                              | 每次弹卡，带改动内容                                        |
| 搜索、列举 | 同一类在这个对话里选过「本对话不再询问」                                                                                                    | 弹卡；设置里可改成一律不许。搜出来的文档不自动授权          |

- 「用户给了什么」只认用户自己发的消息（面板插件接口 17 的 `userWords`），文档内容、Agent 回复里的链接骗不到授权。
- 子对话继承父对话的读权限，不继承写权限。
- 不提供删除、改权限、改分享、发消息、原始命令。
- 终端里直接调 `lark-cli` 由工具前钩子拦下，脚本里间接调用由 PATH 垫片（`bin/`）挡；用户放行后在命令前加 `FEISHU_LARK_RAW=1` 才能穿过。用完整路径调用拦不到（设置页写明了）。
- 长内容写到插件数据目录的缓存（24 小时后清），不写进项目目录。
- 每次调用记审计日志（不记内容，90 天），设置 → 插件参数 → 飞书 →「运行状态」里查看、筛选、清空。

## 开发

- 工具定义按注册表：`server/feishu/ops/*.ts`（一个操作一条 `OpDef`），权限闸 `server/feishu/gate.ts`。
- 单测：`node scripts/test.mjs feishu`，用 `test/fake-lark-cli.mjs`（按 lark-cli 的 JSON 信封返回的假 CLI）。
