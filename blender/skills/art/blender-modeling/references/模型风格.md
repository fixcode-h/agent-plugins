# 按模型风格建模（Blender 做法）

面板的风格库有「3D 模型」一类（通用、日式二次元卡通、写实、真实机械结构、风格化手绘、低多边形、Q 版萌系、体素、科幻硬表面、中式古风、哥特、欧美写实卡通，用户也能复制后改）。
建模对话开始时，面板会把选中风格的**约束要点**接在消息后面（「## 模型风格：…」，按造型 / 比例 / 拓扑 / 细节 / 结构 / 材质与着色 / 描边 / 验收 / 避免分组）。约束要点说「做成什么样」，这份文件说「在 Blender 里怎么做到」。

## 总原则

- 约束要点优先于本技能里的通用默认值；要点没提到的方面按通用做法。
- 先定风格再动手：比例、拓扑密度、材质路线在第一步就按风格定，不要建完再「刷风格」。
- 中途换了风格（消息里出现「模型风格改成了：…」）：只管之后的步骤，已经建好的部分不推倒重来；用户明确要求时再返工。
- 质检时把「验收」组逐条过一遍，每条给出截图或数值证据。

## 材质路线

| 路线 | 适用风格 | Blender 做法 | 网页预览（glTF）里看到的 |
| --- | --- | --- | --- |
| PBR | 通用、写实、真实机械结构、科幻硬表面、哥特、中式古风 | Principled BSDF；颜色在 Base Color，金属度只取 0 或 1，粗糙度按材质给（抛光金属 0.15–0.3、喷漆 0.35–0.5、木头 0.5–0.7、石头 0.7–0.9） | 基本一致 |
| 卡通着色（cel） | 日式二次元卡通、欧美写实卡通、Q 版萌系 | EEVEE：Diffuse BSDF → Shader to RGB → ColorRamp（Constant，2–3 段）→ Emission；亮暗两色写在 ColorRamp 上 | Shader to RGB 导不出去，预览只显示 Base Color；最终效果用 Blender 渲染截图证明 |
| 手绘 / 平涂 | 风格化手绘、低多边形、体素 | Principled BSDF 只用 Base Color（或顶点色），粗糙度 0.8–1、金属度 0；手绘明暗画进贴图或顶点色 | 一致 |

- **预览的限制要告诉用户**：卡通着色、Shader to RGB、几何节点、程序纹理在网页预览里看不到，质检截图用 Blender 渲染（`blender_see` 或 `capture_views.py`）。
- 程序纹理要进 glTF 时先烘焙成图片贴图。

## 描边（卡通类风格）

反向外壳（inverted hull），预览和导出都能看到：
1. 复制网格（或加 Solidify 修改器：厚度 = 物体尺寸的 0.5%–1.5%，勾 Flip Normals，Material Offset 指到描边材质）。
2. 描边材质：Emission 纯色（多用比底色深的同色系，不用纯黑），设置里开 Backface Culling；EEVEE 下 Blend Mode 用 Opaque。
3. 描边粗细跟视距走：角色头身、手指这些小部件单独调薄。
4. 在最终的缩放和变换都应用之后再加描边，否则粗细不均。

## 拓扑密度

| 风格 | 主体面数参考 | 要点 |
| --- | --- | --- |
| 低多边形 | 单件几十到几百面 | 平直着色（Shade Flat），面朝向决定明暗，不加细分 |
| 体素 | 按格子数算 | 统一格子尺寸，用实例或 Remesh（Blocks）对齐网格，不要斜面 |
| 卡通类 | 中等 | 轮廓线处加环线保证剪影圆滑；法线朝向影响色阶边界，脸部可用数据传递修法线 |
| 写实 / 机械 / 科幻 | 中高 | 倒角（Bevel 修改器，宽度按真实尺寸：小件 1–2 mm、大件 3–5 mm）+ 加权法线（Weighted Normal），硬边不靠细分堆面 |

## 结构类风格的检查（真实机械结构、科幻硬表面）

- 运动件之间留间隙（常用 1–3 mm），转轴、铰链、滑轨要有对应的孔、座和限位。
- 紧固件（螺栓、铆钉）按真实规格和间距排，不随手撒。
- 能动的部件单独成物体、原点放在转轴上，旋转一遍确认不穿插（`diagnose_overlap.py`）。

## 比例类风格（Q 版萌系、日式二次元卡通、欧美写实卡通）

- 头身比按约束要点（Q 版 2–3 头身）在第一步用参考线或空物体标出来，后续按它建。
- 先做剪影：正面、侧面各截一张纯色轮廓图，对照参考再加细节。
